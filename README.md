# Solar System Explorer

An interactive 3D solar-system experience built while learning Next.js,
React, TypeScript, and Three.js.

## Current features

- Interactive Sun and Earth
- Planet rotation and orbital motion
- Camera controls with OrbitControls
- Object selection using raycasting
- Animated camera focus
- Scientific information panel
- Pause and resume controls
- Simulation-speed control
- Orbit-path visibility control
- Loading and error states

## Technology

- Next.js
- React
- TypeScript
- Three.js
- Tailwind CSS

## Getting started

Install dependencies:

```bash
npm install
```
